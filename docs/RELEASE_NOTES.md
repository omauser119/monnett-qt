# v0.1.0

Первый выпуск независимого Monnett-клиента для Linux на C++20 / Qt 6.

- Красно-чёрный интерфейс с левым меню и несколькими аккаунтами.
- Тестовый сервер добавляется жестом Shift+Alt+правая кнопка мыши по «Добавить аккаунт».
- Лента, Discover, профили, поиск, истории, публикации медиа, комментарии, уведомления и квоты.
- Matrix/E2EE через libQuotient; текст, файлы, реакции, история и повтор отправки.
- Все 167 клиентских операций каждой среды доступны в каталоге. Admin/webhook/JobRunr исключены.
- Secret Service для токенов, объединение refresh, локальные HTTP- и UI-тесты, CI.

Сборка проверена на Arch Linux / Omarchy, Qt 6.11.2, libQuotient 0.9.6.1. Архив бинарной сборки рассчитан на совместимый Arch x86_64 с системными Qt 6.11.2, Qt Multimedia, libsecret и стандартными библиотеками. Это не универсальный AppImage. Для других дистрибутивов используйте исходники и совместимые версии зависимостей.

Требуется пользовательский аккаунт для живых операций. Авторизованные сценарии с настоящим сервером и E2EE между аккаунтами не проверены. Отдельного UI восстановления Matrix key backup / cross-signing нет. Редкие операции представлены схемами API, а не отдельными экранами. Подробности и сборка — в README.
